<h2 align="center">About The Project</h2>

<p align="center">
  This project is a modern single-page portfolio website designed to showcase projects,
  skills, and personal information through a clean and professional user interface.
</p>

<p align="center">
  It was developed as a practical front-end training project with a focus on building
  responsive layouts using CSS Flexbox, CSS Grid, Bootstrap, and responsive design techniques.
</p>

<p align="center">
  The website also includes a Dark Mode feature and interactive carousel sections
  implemented using jQuery Owl Carousel.
</p>

<h2 align="center">Responsive Design</h2>

<p align="center">
  The website is fully responsive and designed to provide a consistent user experience
  across mobile, tablet, laptop, and desktop screens.
</p>

<p align="center">
  Responsive layouts are implemented using CSS Flexbox, CSS Grid, CSS Media Queries,
  and Bootstrap breakpoints.
</p>

---

<h2 align="center">Dark Mode</h2>

<p align="center">
  The website includes a Dark Mode feature that allows users to switch between
  light and dark themes for a more comfortable browsing experience.
</p>

<p align="center">
  The theme switching functionality is implemented using JavaScript.
</p>

---

<h2 align="center">Owl Carousel</h2>

<p align="center">
  jQuery Owl Carousel is used to create interactive and responsive carousel sections.
  The carousel adapts to different screen sizes for a smooth user experience.
</p>
